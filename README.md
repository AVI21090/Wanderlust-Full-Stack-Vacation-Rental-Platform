# AIR-BNB-REPLICA
THIS PROJECT IS BASICALLY AIR  BNB REPLICA USING FRONTEND(HTML,CSS AND JAVASCRIPT),BACKEND(NODE JS WITH EXPRESS),DATABASE(MONGO DB)

Features

User Authentication: Secure sign-up, login, and logout functionality.

Property Listings: Browse and view detailed information for various properties.

Booking System: Users can book a property for specific dates.

Search and Filter: Search for properties based on location, price, etc.

Responsive Design: The application is built to be accessible on different screen sizes (desktops, tablets, and mobile phones).

Host Dashboard: (If you have this feature) A dedicated section for hosts to create, edit, and delete their own listings.
